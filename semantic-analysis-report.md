## Cross-Cutting Semantic Analysis Roadmap (Recommended)

1. Build a dedicated semantic pass interface with a diagnostics collector (errors/warnings). Avoid `System.err` in core logic.
2. Unify symbol table model (choose the Scope tree or the stack model) and add data types.
3. Add missing getters in AST nodes to avoid using `toString()` or `getChildren()` for structural access.
4. Add symbol binding links in AST nodes (identifier -> symbol) during resolution.
5. Introduce a simple type system for Flask and Jinja (number, string, bool, none, list, set, object).
6. Add semantic tests for invalid inputs with expected error lists.

End of report.
